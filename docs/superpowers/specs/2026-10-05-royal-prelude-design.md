# Design: บทนำพระราชกรณียกิจก่อนบทเปิดโรคหลอดเลือดสมอง

- **วันที่:** 2026-10-05
- **สถานะ:** เจ้าของโปรเจกต์อนุมัติ spec ฉบับเต็มแล้ว พร้อมทำ implementation plan
- **ต้นฉบับเนื้อหาและภาพ:** `docs/บอร์ดนิทรรศการเฉลิมพระเกียรติWRB12_4x2m.png`
- **ตำแหน่งในเรื่อง:** ก่อนหน้า `Opening` เดิม โดยไม่เปลี่ยนข้อความของบทโรคหลอดเลือดสมอง

## เป้าหมาย

1. เพิ่มบทนำเฉลิมพระเกียรติที่เปิดด้วยพระบรมฉายาลักษณ์พระบาทสมเด็จพระเจ้าอยู่หัว ก่อนเข้าสู่หน้า “ทุกนาทีที่ช้า คือสมองที่สูญเสีย”
2. นำเสนอพระราชกรณียกิจด้านการออกกำลังกายและการสร้างเสริมสุขภาพของพระบาทสมเด็จพระเจ้าอยู่หัวและสมเด็จพระนางเจ้าฯ พระบรมราชินี
3. ใช้ข้อความจากบอร์ดต้นฉบับทุกคำ โดยปรับเฉพาะการแบ่งย่อหน้าและการตัดบรรทัดให้เหมาะกับเว็บ
4. ทำให้ประสบการณ์บนมือถืออ่านง่ายก่อน แล้วใช้พื้นที่แท็บเล็ตและ desktop อย่างตั้งใจโดยไม่ลดทอนเนื้อหา
5. เชื่อมบรรยากาศเฉลิมพระเกียรติเข้าสู่บทเรียนโรคหลอดเลือดสมองเดิมอย่างต่อเนื่อง

## ไม่อยู่ในขอบเขต

- ไม่แก้ตัวเลข คำแนะนำ หรือข้อเท็จจริงทางการแพทย์ในบทเดิม
- ไม่เพิ่มพระราชกรณียกิจหรือข้อความเชิงประวัติศาสตร์ที่ไม่มีอยู่ในบอร์ดต้นฉบับ
- ไม่เปลี่ยนลำดับบทที่ 1–8 แบบฝึก บทปิด หรือ footer
- ไม่สร้างภาพใหม่ด้วย generative AI และไม่ค้นหาภาพจากภายนอก
- ไม่เพิ่มปุ่มข้ามบทนำหรือ navigation ชุดใหม่

## การตัดสินใจหลัก

| เรื่อง | ตัดสินใจ |
|---|---|
| รูปแบบ | บทนำแบบนิทรรศการที่เคลื่อนไปกับการอ่าน |
| ขอบเขตบุคคล | รวมพระบาทสมเด็จพระเจ้าอยู่หัวและสมเด็จพระนางเจ้าฯ พระบรมราชินี |
| ข้อความ | ใช้ตามบอร์ดทุกคำ ปรับได้เฉพาะย่อหน้าและการตัดบรรทัด |
| ภาพ | ตัดจากบอร์ดต้นฉบับและแปลงเป็น WebP สำหรับเว็บ |

| Motion | crossfade เบาเฉพาะ gallery ที่ enhanced แล้ว; reduced motion แสดงทันที |

## 1. ลำดับเรื่องและความหมาย

ลำดับเนื้อหาในหน้าเป็นดังนี้:

1. **พระบรมฉายาลักษณ์:** หัวเรื่อง “แสงแห่งพระบารมี” พระบรมฉายาลักษณ์พร้อมกรอบทอง และเครื่องหมายแคมเปญ WRB12
2. **คำนำพระราชกรณียกิจ:** “สู่สุขภาพดีของปวงชน” และคำถวายพระเกียรติตามบอร์ด
3. **พระมหากษัตริย์และพระราชินี ผู้ทรงเป็นต้นแบบแห่งการออกกำลังกาย:** ใช้ภาพทรงจักรยานประกอบข้อความตามบอร์ด
4. **สมเด็จพระนางเจ้าฯ พระบรมราชินี ทรงเป็นแบบอย่างอันประเสริฐแห่งการมีสุขภาวะที่สมบูรณ์:** ใช้ภาพทรงวิ่งประกอบข้อความตามบอร์ด
5. **รวมใจคนไทยสู่การสร้างเสริมสุขภาพ:** แสดงข้อความ Bike for Mom, Bike for Dad และ Bike อุ่นไอรักตามบอร์ด โดย gallery แสดงภาพสองภาพคู่กัน
6. **บทเปิดเดิม:** เข้าสู่ “ทุกนาทีที่ช้า คือสมองที่สูญเสีย” โดยใช้พื้นกรมท่าเดิมเป็นจังหวะเปลี่ยนเรื่อง

ไม่มี CTA ที่บังคับให้แตะเพื่อเข้าเนื้อหา การเลื่อนต่อจะพาผู้อ่านเข้าสู่บทเดิมโดยตรง

## 2. โครงหน้าและ semantic structure

ลำดับใน `src/app/page.tsx`:

```tsx
<ProgressBar />
<RoyalPrelude />
<Opening />
<Chapter1 />
// ...บทเดิมต่อไป
```

- `RoyalPrelude` ใช้ `<section id="royal-prelude">`
- “แสงแห่งพระบารมี” เป็น `h1` หลักของเอกสาร
- “สู่สุขภาพดีของปวงชน” เป็น `h2`
- หัวข้อพระราชกรณียกิจทั้งสามช่วงเป็น `h3`
- หัวเรื่องใน `Opening` เดิมเปลี่ยนจาก `h1` เป็น `h2` โดยข้อความไม่เปลี่ยน
- `ProgressBar` ยังซ่อนอยู่ตลอด Royal Prelude และ Opening และเริ่มแสดงเมื่อเข้าสู่บทที่ 1 ตามตรรกะเดิม
- เนื้อหาแต่ละช่วงอยู่ใน DOM ครบตั้งแต่ render แรก ไม่พึ่ง animation เพื่อให้ค้นหา อ่านด้วย screen reader และอ่านเมื่อ JavaScript ล้มเหลวได้

## 3. Component และข้อมูล

### `src/content/royal-prelude.ts`

เก็บข้อความตามบอร์ดและข้อมูลภาพแบบ typed data:

```ts
type RoyalDuty = {
  id: string;
  title: string;
  body: readonly string[];
  image: { src: string; alt: string };
};
```

- แยก `body` ตามย่อหน้าในบอร์ดโดยไม่เรียบเรียงคำใหม่
- คงปี พ.ศ. พระนาม ชื่อกิจกรรม เครื่องหมายคำพูด และการสะกดจากต้นฉบับ
- เก็บ alt text แยกจากข้อความที่มองเห็น เพราะ alt ต้องบรรยายสิ่งที่อยู่ในภาพ ไม่ทำซ้ำย่อหน้าทั้งหมด

### `RoyalPrelude`

เป็น Server Component ทำหน้าที่:

- เรนเดอร์ hero พระบรมฉายาลักษณ์
- เรนเดอร์คำนำและข้อความพระราชกรณียกิจทั้งหมด
- ส่งรายการพระราชกรณียกิจให้ gallery enhancement
- คง inline media ไว้เป็น fallback เมื่อไม่มี JavaScript

### `RoyalGallery`

เป็น Client Component ขนาดเล็ก ทำหน้าที่เฉพาะ desktop enhancement:

- ใช้ `IntersectionObserver` ตรวจข้อความช่วงที่กำลังอ่าน
- เปลี่ยนภาพ sticky ตามช่วงด้วย class/state เท่านั้น
- เพิ่ม class `is-enhanced` หลัง mount แล้วเท่านั้น เพื่อไม่ซ่อน inline media ก่อน JavaScript พร้อม
- ขั้นที่สามแสดงภาพทรงจักรยานและทรงวิ่งคู่กัน
- ไม่แก้ `window.scrollY` และไม่อ่าน layout ซ้ำใน scroll handler

หาก observer หรือ JavaScript ใช้งานไม่ได้ inline media และข้อความทุกช่วงยังอยู่ใน document flow ตามปกติ

## 4. ภาพและการโหลด

เก็บไฟล์ที่ใช้จริงใน `public/royal/`:

| ไฟล์ | ที่มา | การใช้ |
|---|---|---|
| `rama-x-portrait.webp` | พระบรมฉายาลักษณ์พร้อมกรอบทองจากฝั่งซ้ายของบอร์ด | Hero; eager/high priority |
| `rama-x-cycling.webp` | ภาพทรงจักรยานจากฝั่งขวาของบอร์ด | พระราชกรณียกิจช่วงที่ 1 |
| `queen-running.webp` | ภาพทรงวิ่งจากฝั่งขวาของบอร์ด | พระราชกรณียกิจช่วงที่ 2 |

- เก็บไฟล์ PNG ต้นฉบับใน `docs/` เป็นหลักฐานและแหล่งตัดภาพ ไม่โหลดไฟล์ 11,339 × 5,670 px ในหน้าเว็บ
- ใช้ `next/image` พร้อม `width`/`height`, `sizes` และ `aspect-ratio` ที่ตรงกับ layout
- ภาพนอกจอแรกใช้ lazy loading
- ไม่เพิ่ม CSS drop shadow; มิติของกรอบทองที่ติดมากับภาพต้นฉบับถือเป็นส่วนหนึ่งของภาพ
- ไม่ crop พระพักตร์ พระวรกาย หรือบุคคลสำคัญด้วย `object-fit` แบบที่เปลี่ยนตาม viewport; เตรียม crop คงที่จากต้นฉบับแทน

Alt text ที่ตั้งใจใช้:

- “พระบรมฉายาลักษณ์พระบาทสมเด็จพระวชิรเกล้าเจ้าอยู่หัว”
- “พระบาทสมเด็จพระเจ้าอยู่หัวทรงจักรยานร่วมกับประชาชน”
- “สมเด็จพระนางเจ้าฯ พระบรมราชินีทรงวิ่งร่วมกับนักวิ่ง”

## 5. Visual system

เพิ่ม token กลุ่ม Royal Prelude ใน `src/app/globals.css` และอธิบายใน `DESIGN.md`:

| token | Light | Dark | ใช้กับ |
|---|---|---|---|
| `--royal-paper` | `#EEF3FB` | `#101B34` | พื้นช่วงเฉลิมพระเกียรติ |
| `--royal-ink` | `#173465` | `#EEF3FB` | ข้อความย่อหน้าและหัวเรื่องกรมท่า |
| `--royal-gold` | `#8A641D` | `#E8C878` | หัวเรื่องใหญ่ เส้นแบ่ง และรายละเอียดสำคัญ |
| `--royal-blue` | `#1674B8` | `#65B7E8` | แถบหรือพื้นเน้นสีน้ำเงินจากบอร์ด |

ค่าคอนทราสต์หลัก:

- `royal-ink` บน `royal-paper` โหมดสว่างประมาณ 10.99:1
- `royal-gold` บน `royal-paper` โหมดสว่างประมาณ 4.81:1
- `royal-gold` บน `royal-paper` โหมดมืดประมาณ 10.55:1

ข้อกำหนด:

- สีทองใช้กับหัวเรื่อง เส้น และข้อความที่ผ่าน 4.5:1 เท่านั้น
- ย่อหน้ายาวใช้ `royal-ink` เพื่อความอ่านง่าย
- สีแดงยังใช้เฉพาะความเร่งด่วนในบทโรคหลอดเลือดสมอง ไม่ใช้ตกแต่ง Royal Prelude
- ไม่ใช้ gradient, glassmorphism หรือ CSS shadow
- ใช้ Anuphan เดิม: หัวเรื่อง 700 เนื้อหา 400; line-height เนื้อหา 1.65 และหัวเรื่องไม่น้อยกว่า 1.22
- ไม่เพิ่ม letter-spacing ให้ข้อความไทย

## 6. Responsive layout

### Phone: 320–699px

- Hero สูงอย่างน้อย `100svh` พร้อม safe area
- เรียงหัวเรื่อง → พระบรมฉายาลักษณ์ → เครื่องหมายแคมเปญ
- พระบรมฉายาลักษณ์คุมด้วยความสูงและความกว้างสูงสุด ไม่ให้ล้น 360 × 640
- เนื้อหาพระราชกรณียกิจเรียงภาพ → หัวข้อ → ย่อหน้า
- ไม่มี sticky gallery และไม่มีข้อความซ้อนบนภาพ
- ความกว้างบรรทัดไม่เกินประมาณ 36em และไม่มี scroll แนวนอนตั้งแต่ 320px

### Tablet portrait: `min-width: 700px` และ `min-height: 900px`

- Hero ใช้สองคอลัมน์: หัวเรื่องและเครื่องหมายแคมเปญด้านหนึ่ง พระบรมฉายาลักษณ์อีกด้านหนึ่ง
- ช่วงพระราชกรณียกิจใช้สองคอลัมน์สลับภาพกับข้อความเพื่อใช้พื้นที่แนวตั้งให้คุ้ม
- ไม่เปิด sticky gallery เพื่อให้การอ่านบนจอสัมผัสเป็นธรรมชาติ

### Desktop และ tablet landscape: `min-width: 861px`

- หัวเรื่องพระราชกรณียกิจเต็มความกว้างก่อนเข้า gallery
- gallery เป็นสองคอลัมน์: ภาพ sticky ทางซ้าย ข้อความสามช่วงทางขวา
- แต่ละข้อความมีระยะก่อนและหลังพอให้ observer เปลี่ยนภาพโดยไม่กระพริบถี่
- กำหนดค่าที่ tablet เปลี่ยนไว้ใหม่ให้ครบ เพื่อไม่รับ style แนวตั้งโดยไม่ตั้งใจ

### Short landscape: `(orientation: landscape) and (max-height: 500px)`

- ยกเลิก sticky และกลับเป็นแถวภาพ–ข้อความแบบย่อ
- ลดระยะ hero แต่ยังแสดงหัวเรื่องและพระบรมฉายาลักษณ์ครบ
- ไม่ซ่อนข้อความจากบอร์ด

## 7. Motion และ progressive enhancement

- พระบรมฉายาลักษณ์ไม่มี parallax, zoom หรือการเคลื่อนไหวตกแต่ง
- การเคลื่อนไหวจุดเดียวคือ crossfade ภาพใน sticky gallery บน desktop
- ใช้ `opacity` เท่านั้นและไม่เปลี่ยน layout ระหว่าง transition
- CSS transition อยู่ใต้ `@media (prefers-reduced-motion: no-preference)`
- เมื่อ reduced motion ภาพเปลี่ยนทันทีและไม่มี entrance animation
- เมื่อไม่มี JavaScript จะไม่ใช้ enhanced gallery และ inline media ทั้งหมดจะแสดงตามลำดับ

1. เพิ่ม test ให้ข้อมูล Royal Prelude มีสามช่วง มี path ภาพที่มีอยู่จริง และไม่มีข้อความว่าง

3. `pnpm content:review` แล้ว `docs/medical-review.md` ไม่เปลี่ยนโดยไม่ตั้งใจ
4. `pnpm test`, `pnpm lint`, `pnpm exec tsc --noEmit` และ `pnpm build` ผ่าน
5. `pnpm shots capture` ตรวจ overflow และเก็บภาพ Hero/Gallery เพิ่มจากฉากเดิม

### Visual and interaction

ตรวจตามลำดับ:

1. 360 × 640
2. 390 × 844
3. 430 × 932
4. 768 × 1024 และ 820 × 1180
5. 1024 × 768 และ 1180 × 820
6. 740 × 360
7. 1280 × 800 ขึ้นไป

ทุกรอบต้องตรวจ:

- light mode และ dark mode
- reduced motion อย่างน้อยหนึ่ง viewport
- ไม่มี horizontal overflow ตั้งแต่ 320px
- พระบรมฉายาลักษณ์และบุคคลสำคัญไม่ถูก crop เสียความหมาย
- ข้อความตรงกับบอร์ดทีละย่อหน้า
- heading order, alt text และการอ่านด้วย keyboard/screen reader
- หน้า Opening และบทที่ 1–8 เดิมไม่เปลี่ยน layout นอกเหนือจาก heading semantic
- ไม่มี console error และ static fallback อ่านได้เมื่อ animation ไม่ทำงาน

## 10. เกณฑ์ยอมรับ

งานถือว่าเสร็จเมื่อ:

- ผู้ใช้เห็นพระบรมฉายาลักษณ์เป็นเนื้อหาแรกของหน้า
- เมื่อเลื่อนลงพบพระราชกรณียกิจของทั้งพระบาทสมเด็จพระเจ้าอยู่หัวและสมเด็จพระนางเจ้าฯ พระบรมราชินีครบตามบอร์ด
- ข้อความในหน้าเว็บตรงกับบอร์ดต้นฉบับทุกคำ ยกเว้นการแบ่งย่อหน้าและ line break
- มือถืออ่านได้โดยไม่มี pin หรือเนื้อหาถูกตัด
- แท็บเล็ตมี layout สองคอลัมน์ที่ตั้งใจออกแบบ และ desktop มี sticky gallery ที่ progressive-enhance เท่านั้น
- dark mode, reduced motion และ no-JavaScript fallback ใช้ได้
- หน้า stroke เดิมทำงานและแสดงผลเหมือนก่อนเพิ่ม Royal Prelude
