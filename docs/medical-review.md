# รายการตรวจทานทางการแพทย์

สร้างด้วย `pnpm content:review` ห้ามแก้ไฟล์นี้ด้วยมือ ให้แก้ข้อความใน `src/content/` แล้วรันใหม่

ข้อความเหล่านี้มาจากความรู้ทั่วไป (★ ในสคริปต์) หรือเป็นข้อความร่างใหม่ ต้องให้แพทย์หรือพยาบาลตรวจก่อนเผยแพร่

| ตำแหน่ง | ข้อความบนหน้าเว็บ | สิ่งที่ต้องตรวจ | ผลตรวจ |
|---|---|---|---|
| บทที่ 1 คำโปรย | สมองทำงานได้ทุกวินาทีเพราะมีเลือดไหลไปเลี้ยงไม่หยุด บทนี้จะพาไปดูว่าเกิดอะไรขึ้นเมื่อเลือดไปไม่ถึง | คำโปรยร่างใหม่ ไม่มีในสคริปต์ |  |
| บทที่ 1 ขั้น 1 | สมองหนักเพียงราว 2% ของน้ำหนักตัว แต่ใช้ออกซิเจนราว 20% ของทั้งร่างกาย | สมองหนักราว 2% ของน้ำหนักตัว และใช้ออกซิเจนราว 20% |  |
| บทที่ 1 ขั้น 2 | หลอดเลือดคือถนนส่งเสบียงเข้าเมือง เลือดนำออกซิเจนและอาหารไปเลี้ยงเซลล์สมองตลอดเวลา และสมองแทบไม่มีพลังงานสำรองไว้เลย | สมองแทบไม่มีพลังงานสำรอง |  |
| บทที่ 1 ขั้น 4 | แบบที่ 1: ตีบหรือตัน พบบ่อยที่สุด ราว 8 ใน 10 ราย ลิ่มเลือดหรือคราบไขมันไปอุดหลอดเลือด เลือดจึงผ่านไปไม่ได้ | สัดส่วนสโตรกชนิดตีบหรือตันราว 8 ใน 10 |  |
| บทที่ 1 ขั้น 5 | แบบที่ 2: หลอดเลือดแตก ราว 2 ใน 10 ราย หลอดเลือดในสมองแตก เลือดรั่วออกมากดเนื้อสมอง มักเกี่ยวข้องกับความดันโลหิตสูง | สัดส่วนสโตรกชนิดหลอดเลือดแตกราว 2 ใน 10 และความเกี่ยวข้องกับความดันโลหิตสูง |  |
| บทที่ 1 ขั้น 6 | ทั้งสองแบบมีอาการคล้ายกันมาก แต่รักษาต่างกันโดยสิ้นเชิง แยกได้ด้วยการสแกนสมองที่โรงพยาบาลเท่านั้น จึงห้ามรักษาเองที่บ้าน | การแยกชนิดด้วยการสแกนสมองเท่านั้น และคำเตือนห้ามรักษาเองที่บ้าน |  |
| บทที่ 1 ขั้น 7 | อาการที่หายไปเอง ก็ยังต้องไปโรงพยาบาล บางครั้งอาการเกิดขึ้นแล้วหายภายในไม่กี่นาที เรียกว่าสโตรกเตือน (TIA) เป็นสัญญาณว่าอาจเกิดสโตรกจริงตามมา ต้องรีบพบแพทย์เช่นกัน | นิยามและคำแนะนำเรื่องสโตรกเตือน (TIA) |  |
| บทที่ 2 คำโปรย | สโตรกไม่ได้เป็นแค่โรคของผู้สูงอายุ และหลายอย่างในชีวิตประจำวันเพิ่มความเสี่ยงได้โดยไม่รู้ตัว | คำโปรยร่างใหม่ ไม่มีในสคริปต์ |  |
| บทที่ 2 ขั้น 3 | พฤติกรรมการกิน: หวาน มัน เค็ม กินเป็นประจำจะนำไปสู่เบาหวาน ไขมันในเลือดสูง และความดันโลหิตสูง ซึ่งล้วนทำร้ายหลอดเลือด | กลไกที่พฤติกรรมการกินหวาน มัน เค็ม ทำร้ายหลอดเลือด |  |
| บทที่ 2 ขั้น 4 | ยาเสพติด: บุหรี่ กัญชา กระท่อม และอื่นๆ บุหรี่ทำลายผนังหลอดเลือดและทำให้เลือดจับตัวเป็นลิ่มง่ายขึ้น สารเสพติดบางชนิดทำให้ความดันพุ่งสูงหรือหลอดเลือดหดตัวฉับพลัน | กลไกของบุหรี่และสารเสพติดต่อหลอดเลือด |  |
| บทที่ 2 ขั้น 5 | มลพิษ: ฝุ่น PM2.5 ฝุ่นละเอียดมากเข้าสู่กระแสเลือดได้ และกระตุ้นการอักเสบของหลอดเลือด | กลไกของฝุ่น PM2.5 ต่อหลอดเลือด |  |
| บทที่ 2 ขั้น 6 | ผลแทรกซ้อนจากการฉีดฟิลเลอร์ หากสารถูกฉีดเข้าหลอดเลือดโดยไม่ตั้งใจ อาจไหลไปอุดหลอดเลือดที่ตาหรือสมองได้ ควรทำกับแพทย์ที่ได้รับอนุญาตเท่านั้น | กลไกการอุดตันจากฟิลเลอร์ และคำแนะนำให้ทำกับแพทย์ที่ได้รับอนุญาต |  |
| บทที่ 2 ขั้น 7 | ความเครียด นอนน้อย พักผ่อนไม่เพียงพอ ทำให้ความดันโลหิตสูงขึ้นและร่างกายฟื้นตัวได้ไม่ดี | ผลของความเครียดและการนอนน้อยต่อความดันโลหิต |  |
| บทที่ 2 แบบสำรวจ | กินหวาน มัน เค็มเป็นประจำ, สูบบุหรี่หรือใช้สารเสพติด, อยู่ในที่ที่มีฝุ่น PM2.5 บ่อย, ฉีดฟิลเลอร์ หรือกำลังคิดจะฉีด, เครียด นอนน้อย พักผ่อนไม่พอ | ป้ายตัวเลือกร่างใหม่จากหัวข้อปัจจัยเสี่ยง ไม่มีในสคริปต์ |  |
